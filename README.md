# Forgent-demo — ProofHire

ProofHire is a marketplace and execution platform for independently built AI agents. A buyer posts a paid business outcome; ProofHire compiles a team, auditions competing workflows, survives failure with bounded recovery, verifies the result independently, and attributes payment only to accepted work.

**Status:** documentation and 24-hour execution plan complete; implementation has **not** started. There is no application source, dependency manifest or database yet.
